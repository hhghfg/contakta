1. Определения

Оператор персональных данных (Оператор): Консультационная компания КОНТАНТА, осуществляющая обработку персональных данных.

Персональные данные: Любая информация, относящаяся к определённому или определяемому физическому лицу (субъекту персональных данных).

Обработка персональных данных: Любое действие (операция) или совокупность действий, совершаемых с использованием средств автоматизации или без использования таких средств с персональными данными.

Конфиденциальность персональных данных: Обязательное требование в соответствии с законодательством, в соответствии с которым информация не должна передаваться без согласия субъекта персональных данных третьим лицам.

2.1 Данные, которые вы предоставляете добровольно:

  • Фамилия, Имя, Отчество - при заполнении формы заявки
  • Номер телефона - для связи и консультации

  • Возраст - для определения соответствия требованиям (опционально)
  • Город проживания - для локализации услуг (опционально)

2.2 Данные, которые собираются автоматически:

  • IP-адрес - для безопасности и аналитики
  • User Agent браузера - для оптимизации сайта
  • Дата и время обращения - в целях логирования
  • Cookies и localStorage - для функционирования сайта

3. Правовые основания обработки персональных данных

Мы обрабатываем ваши персональные данные на основании:

  • Ст. 6 (1) буква (а) GDPR: Ваше явное согласие на обработку
  • Ст. 9 Федерального закона № 152-ФЗ: Согласие субъекта персональных данных
  • Ст. 10 Федерального закона № 152-ФЗ: Необходимость обработки для исполнения договора
  • Требования РКН (Роскомнадзор): Соответствие нормативным требованиям Российской Федерации

Мы НЕ продаём ваши данные третьим лицам.

Данные передаются только:

7. Защита персональных данных

7.1 Технические меры защиты:

  • 🔒 Шифрование: Передача данных по HTTPS с SSL/TLS
  • 🔐 Хеширование паролей: BCRYPT хеширование для администраторов
  • 🛡️ Защита от атак: Валидация входных данных, SQL injection защита
  • 📝 Логирование: Все действия с данными записываются в лог
  • ⏰ Таймауты сессий: Автоматический выход после 30 минут неактивности

7.2 Организационные меры защиты:

  • 👥 Доступ к данным только авторизованным сотрудникам
  • 📋 Обязательства о конфиденциальности для всех администраторов
  • 🔑 Использование сложных паролей и двухфакторной аутентификации
  • 📞 Регулярный аудит безопасности
