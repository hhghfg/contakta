# Система управления заявками КОНТАНТА v2.0

## 📋 Структура системы

### Роли и права доступа

#### 🔐 Super-Admin
- Полный контроль над системой
- Создание новых администраторов
- Управление правами администраторов
- Просмотр всех заявок
- Просмотр активности администраторов
- Просмотр статистики

**Учетные данные по умолчанию:**
- Username: `superadmin`
- Password: `superadmin123`
- ⚠️ **ИЗМЕНИ ПАРОЛЬ СРАЗУ!**

#### 👤 Admin
- Просмотр всех заявок
- Захват заявок в работу (Assign to Me)
- Изменение статуса заявок
- Добавление примечаний к заявкам
- Просмотр своих назначенных заявок
- Отправка ответов клиентам

#### 👁️ Moderator
- Просмотр заявок (только просмотр)
- Не может изменять статусы
- Не может захватывать заявки

## 🔑 Процесс входа

1. Откройте `/admin/login.html`
2. Введите username и password
3. Система проверяет учетные данные в `storage/admins.json`
4. При успешной аутентификации создается токен (32 байта = 64 символа hex)
5. Токен сохраняется в `storage/sessions.json`
6. Пользователь редиректится на:
   - `/admin/super-admin.html` (если роль = super-admin)
   - `/admin/dashboard.html` (если роль = admin/moderator)

## 💼 Функционал Super-Admin

### Вкладка "Администраторы"

**Создание нового администратора:**
- Имя (обязательное)
- Email (обязательное, валидация)
- Логин (обязательное, уникальное, 3-50 символов)
- Пароль (обязательное, минимум 6 символов, хешируется BCRYPT)
- Роль (Admin или Moderator)

**Таблица администраторов:**
- ID администратора
- Имя
- Email
- Логин
- Роль (Super-Admin, Admin, Moderator)
- Статус (Активен/Неактивен)
- Дата последнего входа
- Действия (Редактировать, Деактивировать)

### Вкладка "Статистика"

- 👥 Всего администраторов
- ✅ Активных администраторов
- 📋 Всего заявок в системе
- 🔴 Новых заявок
- ⏳ В обработке
- ✅ Завершено

### Вкладка "Активность"

- Все действия администраторов логируются
- Дата и время действия
- Имя администратора
- Тип действия (вход, выход, создание админа, изменение заявки)
- IP адрес

## 📋 Функционал Admin/Moderator

### Вкладка "Заявки"

**Статистика быстрого доступа:**
- 🔴 Новых заявок (статус = "new")
- ⭐ Назначено мне (статус = "assigned" и assigned_to_admin_id = мой ID)
- ⏳ В процессе (статус = "processing")
- ✅ Завершено (статус = "completed")

**Фильтры:**
- Поиск по ФИО
- Поиск по номеру телефона
- Фильтр по статусу (Все, Новая, Назначена мне, В обработке, Завершено, Отклонено)

**Таблица заявок:**
- ID заявки
- ФИО
- Телефон (кликабельная ссылка tel:)
- Email (кликабельная ссылка mailto:)
- Статус (цветной значок)
- Назначена (имя администратора или "Не назначена")
- Дата создания
- Кнопка "Открыть"

**Модальное окно заявки:**
- ФИО
- Телефон (tel: ссылка)
- Email (mailto: ссылка)
- Возраст
- Город
- Сообщение
- Текущий статус (dropdown)
- Примечание (textarea)
- Кнопки:
  - "Сохранить изменения" - сохраняет статус и примечание
  - "Забрать в работу" - назначает заявку на вас (статус → "assigned")
  - "Закрыть" - закрывает модальное окно

### Вкладка "Мои заявки"

**Статистика:**
- ⭐ Всего мне назначено
- ⏳ В процессе (мои)
- ✅ Завершено (мои)

**Фильтры:**
- Поиск по ФИО
- Фильтр по статусу (Все, Назначена, В обработке, Завершено)

**Таблица:**
- Только заявки, где assigned_to_admin_id = ваш ID
- Аналогично основной таблице

### Вкладка "Статистика"

- Личный рейтинг
- Количество обработанных заявок
- Процент успеха

## 🔄 Жизненный цикл заявки

1. **Новая** (status: "new")
   - Клиент заполнил форму на сайте
   - Заявка создается через `/api/lead.php`
   - Email отправляется на svo@mos.ru
   - Видна всем администраторам

2. **Назначена** (status: "assigned")
   - Admin нажимает "Забрать в работу"
   - Заявка назначается на этого администратора
   - Видна в его вкладке "Мои заявки"

3. **В обработке** (status: "processing")
   - Admin изменяет статус на "В обработке"
   - Добавляет примечания о проведенных действиях

4. **Завершено** (status: "completed")
   - Admin завершает работу с клиентом
   - Клиент может быть принят на контракт

5. **Отклонено** (status: "rejected")
   - Admin отклоняет заявку
   - Клиент не подходит

## 🔐 Безопасность

### Аутентификация
- Пароли хешируются BCRYPT (PASSWORD_BCRYPT)
- Токены генерируются через `random_bytes(32)` → 64 hex символа
- Сессии хранятся в `sessions.json`

### Авторизация
- Каждый API запрос требует валидный токен
- Проверяется роль пользователя
- Super-Admin может только Super-Admin
- Логируются все действия администраторов

### Валидация
- Email валидируется через FILTER_VALIDATE_EMAIL
- Username: 3-50 символов
- Пароль: минимум 6 символов
- Входные данные санитизируются

## 🚀 Быстрый старт

### 1. Первый вход (Super-Admin)
- Откройте `/admin/login.html`
- Username: `superadmin`
- Password: `superadmin123`
- ⚠️ **ИЗМЕНИ ПАРОЛЬ!** (Пока нет функции смены пароля через UI)

### 2. Создание администраторов
- Перейдите на `/admin/super-admin.html`
- Вкладка "Администраторы"
- Заполните форму и нажмите "Создать администратора"

- Откройте `/admin/login.html`
- Введите учетные данные администратора
- Перейдите на `/admin/dashboard.html`

### 4. Работа с заявками
- Вкладка "Заявки" - все заявки
- Используйте фильтры для поиска
- Нажмите "Открыть" на интересующую заявку
- Нажмите "Забрать в работу" чтобы назначить на себя
- Измените статус и добавьте примечание
- Нажмите "Сохранить изменения"
